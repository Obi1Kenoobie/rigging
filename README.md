# rigging

Rigging repository for utils functions and rig modules


# installation instructions

make sure you have Git Bash installed you can find it here: https://gitforwindows.org/

once installed to clone this repo navigate to your scripts folder (eg. cd C:\\Users\\Mario\\Documents\\maya\\2020\\scripts) and run:

    git clone https://github.com/Obi1Kenoobie/rigging.git

this will clone the rigging repo under your scripts folder and you will be able to import it as python modules


# git instructions

before modifying any code is good practice to run:

    git pull
    
when pushing new code you need to first add the modified files by running:

    git add .
    
then committing the newly added files by running:
    
    git commit -m "commit message"

and finally to push your code to github run:

    git push
